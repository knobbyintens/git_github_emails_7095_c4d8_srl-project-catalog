# Silverpine Research Lab - Public Project Catalog

`catalog.json` lists the lab's projects for the open-source review. Each entry may
carry a `code_url` pointing at the project's public code repository.

Field notes:

- `project_id` - internal identifier
- `title` - paper / project title
- `venue` - publication venue
- `repo_name` - name of the code repository in the lab's code-hosting account, or `null`
  when the project has no public code repository
- `code_url` - public URL of the project's code repository; left empty when the
  repository is not publicly released
